译伴 BuddyTrans v0.2.0 — 安装说明
====================================

本压缩包是一个 Manifest V3 浏览器扩展（Chrome / Edge 通用）。
因为不是从应用商店安装，需要通过「开发者模式 → 加载已解压的扩展程序」导入。

【第一步】解压
把本压缩包解压到一个固定目录，例如：
  D:\Extensions\BuddyTrans
注意：解压后该目录里必须能直接看到 manifest.json、popup.html、background.js 这些文件。
不要再多套一层文件夹，也不要解压到临时目录（临时目录被清理后扩展会失效）。

【第二步】Chrome 安装
1. 地址栏输入 chrome://extensions 回车
2. 打开右上角「开发者模式」开关
3. 点左上角「加载已解压的扩展程序」
4. 选择刚才解压出来的目录（能看到 manifest.json 的那一层）
5. 完成后工具栏出现「译伴 BuddyTrans」图标，点击即可使用

【第二步】Edge 安装
1. 地址栏输入 edge://extensions 回车
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择解压目录
4. 同样在工具栏出现图标

【第三步】允许权限
首次使用整页翻译时，浏览器会询问「是否允许访问所有网站」，选择允许。
这是必要的：扩展需要读取网页内容才能进行双语对照翻译。

【功能入口】
- 点工具栏图标：翻译弹窗
- 右键工具栏图标 →「在边栏中显示」：侧边栏工作台
- 网页中选中文字：划词翻译浮层
- Alt + T：开关整页翻译
- Alt + M：切换 双语 / 仅译文 / 仅原文
（快捷键如未生效，在 chrome://extensions/shortcuts 中查看或重新绑定）

【常见问题】
Q: 提示「清单文件缺失或不可读取」
A: 选错了目录层级。请选择能直接看到 manifest.json 的那个文件夹。

Q: 图标是灰色的 / 点击没反应
A: 到 chrome://extensions 找到本扩展，点卡片上的刷新按钮重新加载。

Q: 翻译一直失败
A: 打开扩展的「设置」，在三条通道（本地模型 / 免费通道 / BYOK）中任选一条并点「测试连接」，
   确认可用后再翻译。默认的免费通道可能受网络环境影响。

Q: 字体没有圆润效果
A: 字体文件在 fonts 目录内，请确认解压完整、未被安全软件拦截。

【隐私说明】
翻译内容仅发送到你自己配置的模型服务端点，扩展本身不收集任何数据。
设置、历史记录保存在浏览器本地存储中。
